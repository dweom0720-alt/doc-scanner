# 문서스캔 (DocScan)

문서를 사진으로 찍어 **배경을 자동으로 잘라내고**, 글자가 읽히는 수준에서 **최대한 저용량 PDF**로 저장하는 안드로이드 앱입니다.

## 쓰는 법
1. **사진 찍기** — 문서를 화면에 비추기만 하면 테두리를 자동으로 잡고, 잠깐 멈추면 저절로 찍어서 문서만 반듯하게 잘라 담습니다. 다음 장을 올려놓으면 또 찍고, 같은 장은 다시 찍지 않습니다. 장수 제한 없음. 필요하면 가운데 버튼으로 직접 찍을 수도 있고, 어두우면 '조명'을 켜세요.
   - 카메라 위쪽에서 **자동 촬영 / 수동 촬영**, **종이 / 모니터**를 고를 수 있습니다(고른 값은 기억됨).
   - **모니터** 모드: 화면 속 문서 페이지만 찾아 잘라냅니다. 문서 경계가 안 보이면(흰 문서가 거의 흰 배경 위에 있는 경우 등) 모니터 화면 전체를 반듯하게 잘라 담습니다.
   - 위쪽 '사진 불러오기'로 갤러리 사진을 여러 장 고르면 똑같이 자동으로 잘라 담습니다.
2. **미리보기** — 담긴 사진을 누르면 크게 볼 수 있습니다. '원본'과 'PDF 결과'(고른 모드로 실제 PDF에 들어갈 모습, 장당 예상 용량 표시)를 오가며 확인하고, 확대·좌우로 넘기기·회전·삭제가 됩니다. 촬영 중에는 오른쪽 아래 작은 사진을 누르면 방금 찍은 장을 볼 수 있습니다.
3. **모드 선택** — 흑백(가장 작음) · 회색 · 컬러
4. **PDF 만들기** — `다운로드/문서스캔` 폴더에 저장되고, 바로 공유·열기 할 수 있습니다.
5. **이어서 찍기** — 중간에 멈췄다가 다시 '이어서 찍기'를 누르면 다음 쪽부터 계속 붙습니다. PDF를 만든 뒤에도 사진이 남아 있어서, 더 찍고 다시 'PDF 만들기'를 누르면 **같은 PDF 파일이 새 쪽까지 포함해 업데이트**됩니다. 다른 문서를 시작하려면 '새 문서'를 누르세요(이미 만든 PDF는 그대로 남음).

## 용량 기준 (A4 글자 문서 1장)
- **흑백**: 약 20~60 KB — 글자 문서 기본 추천
- **회색**: 약 200~400 KB
- **컬러**: 약 200~400 KB — 도장·서명·색이 있는 표가 필요할 때

## 개인정보
- **인터넷 권한이 없습니다.** 스캔한 사진과 PDF는 폰 안에서만 처리되며 밖으로 나가지 않습니다.
- 카메라 권한만 사용합니다.
