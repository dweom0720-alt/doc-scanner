# 문서스캔 (DocScan)

문서를 사진으로 찍어 **배경을 자동으로 잘라내고**, 글자가 읽히는 수준에서 **최대한 저용량 PDF**로 저장하는 안드로이드 앱입니다.

## 쓰는 법
1. **사진 찍기** — 구글 문서 스캐너가 뜹니다. 테두리를 자동으로 잡아 배경을 잘라내고, 여러 장(최대 100장)을 연속으로 찍을 수 있습니다. 갤러리에서 기존 사진을 불러올 수도 있습니다.
2. **모드 선택** — 흑백(가장 작음) · 회색 · 컬러
3. **PDF 만들기** — `다운로드/문서스캔` 폴더에 저장되고, 바로 공유·열기 할 수 있습니다.

## 용량 기준 (A4 글자 문서 1장)
- **흑백**: 약 20~60 KB — 글자 문서 기본 추천
- **회색**: 약 200~400 KB
- **컬러**: 약 200~400 KB — 도장·서명·색이 있는 표가 필요할 때

## 개인정보
- **인터넷 권한이 없습니다.** 스캔한 사진과 PDF는 폰 안에서만 처리되며 밖으로 나가지 않습니다.
- 카메라 권한도 필요 없습니다(구글 Play 스캐너가 대신 처리).
